# Real-vs-Virtual-Grasp-Classification-from-Forearm-sEMG
Machine-learning classification of real vs virtual-reality grasping from three-muscle forearm sEMG (FPL, FDP, FDS). Compares 6 classic classifiers with Riemannian geometry, subject normalisation, LightGBM, MiniRocket, a 1D-CNN and an ensemble, using leave-one-subject-out validation. Includes a full Jupyter training notebook.
